# 2. Objective and architecture

The program tests this falsifiable claim:

> Given a raw breakout-retest signal generated by the existing deterministic logic, a small, calibrated, reproducible Python model can identify a higher-quality subset that outperforms both the raw strategy and fairly tuned deterministic filters without destroying trade frequency.

The architecture is:

```text
Deterministic breakout-retest would-signal
                    ↓
Causal decision-time feature vector
                    ↓
Python meta-label model
                    ↓
Calibrated probability
                    ↓
TAKE / SKIP / ABSTAIN in shadow only
```

The deterministic system continues to own:

```text
signal family

market level
```


## 11.2 Fuzzy setup group

Primary rule:

```text
same symbol
same base family
same direction
level difference <= 0.10 × earlier-signal M5 ATR14
decision timestamps within 10 minutes
break/retest windows overlap
connected-component span <= 20 minutes
```

Algorithm:

1. exact-deduplicate;
2. sort chronologically;
3. build graph edges using the rule;
4. find connected components;
5. split components spanning more than 20 minutes;
6. select earliest valid decision as canonical row;
7. aggregate lanes, magics, duplicate count, source IDs;
8. assign `setup_group_id`.

Sensitivity diagnostics:

```text
0.05 ATR
0.10 ATR primary
0.20 ATR
```

Only 0.10 ATR defines the locked dataset.

`setup_group_id` may not cross train/test boundaries.

Lane, magic, and duplicate count are metadata, not model features.

# 18. Feature budget

For each outer fold:

1. create chronological outer training;
2. remove test setup groups;
3. purge overlap;
4. apply embargo;
5. remove non-trainable labels;
6. reserve chronological calibration tail;
7. use remaining model-fit segment;
8. count positive and negative labels.

Define:

```text
minority_events_fit_fold =
  min(model_fit_positive, model_fit_negative)

minority_events_min =
  minimum minority_events_fit_fold across outer folds

global_feature_budget =
  min(16, floor(minority_events_min / 15))
```

# 22. Purged walk-forward validation

Never use random shuffling.

Use:

```text
5 outer expanding folds
3 inner expanding folds
```

Each sample has:

```text
event_start

```

For each outer fold:

- chronological training before test;
- remove event overlap;
- apply embargo;
- keep groups intact;
- fit transformations on training only;
- reserve disjoint calibration tail;
- select threshold on calibration only;
- evaluate once on outer test.

Embargo:

```text
max(full label horizon, one M5 bar)
```

Support active-market time for the 288-bar horizon.
