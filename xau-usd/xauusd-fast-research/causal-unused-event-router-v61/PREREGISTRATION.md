# V61 Causal Unused-Event Router

V61 is a development-only discovery stage. It keeps the broker-expressible V59
portfolio immutable and asks whether strictly unused action-ledger events can add
enough causal frequency without weakening its edge.

The grid is fixed at four coarse state schemas, three short/long trailing windows,
and four health thresholds: 48 policies. State health uses only outcomes whose
exit precedes the current signal. Candidate selection excludes every signal-time
and direction pair already qualified by any V57 sleeve, including candidates that
were rejected later by portfolio capacity.

Policy selection may use only trades with both signal and exit before
2024-07-01. Confirmation and final outcomes are prohibited in this stage. A V61
pass is not execution authorization; it only permits a separately locked
confirmation/final evaluation.
