# Capital Quote Exhaustion Reversal V30

V30 tests one forward quote-path hypothesis that is mechanically distinct from
the V24.1 continuation burst and the V26 post-gap restart. A candidate exists
only after a fast one-sided impulse establishes an extreme and at least three
counter-direction quote updates confirm a fixed retracement. The trade direction
fades the original impulse.

The July 17 Capital file is used only to verify schema and candidate frequency.
No post-candidate price, return, or P&L from that file is opened. The unchanged
rule is first tested on a separately declared June MT5 tick packet. It may enter
forward collection only if that development firewall passes. Forward evidence
starts on 2026-07-21, after this package is locked.

This package is research-only. It does not authorize model training, Python
predictions, EA consumption, demo trading, live trading, or broker action.
