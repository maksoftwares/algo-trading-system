# XAUUSD Cost-Aware Breakout-Retest V2

Fresh, bounded replay of the repository's historically robust but cost-suspended
breakout-retest family. V2 changes the event universe before scoring by requiring
wide stops and explicit cost feasibility.

Run with:

```powershell
uv run --with pandas --with numpy --with pyarrow --with pytest python run_research.py
```

Research only. A retrospective pass cannot authorize an EA, Python prediction,
demo order, or live order.
