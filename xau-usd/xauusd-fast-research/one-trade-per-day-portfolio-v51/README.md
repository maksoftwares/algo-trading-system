# XAUUSD One-Trade-Per-Day Portfolio V51

V51 tests one fixed, account-feasible Expansion add-on beside the unchanged V50
Core. It targets at least one completed trade per UTC weekday without using a
daily quota and without weakening any existing Core signal, stop, target, or
risk rule.

This package is research only. Run `lock_contract.py --verify` before
`run_study.py`. No model, EA, demo, live, or broker action is authorized.
