# Pullback Swing Replication V7

V7 freezes one interpretable candidate selected from the exposed 2019-2026
frequency screen, then tests it unchanged on the earlier 2016-2018 action-label
period. The candidate uses existing mechanical events, a fixed 2R/36-hour action,
medium H1 ADX, and a directional pullback.

The earlier period is reverse-time replication evidence, not prospective evidence.
Even a pass remains research-only and requires independent MT5 parity plus forward
shadow validation.

Run:

```powershell
python run_v7.py

```
