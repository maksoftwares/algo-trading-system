# One-Trade-Per-Day Unified Portfolio V57

V57 is the shared-account successor to V56. It sends the unchanged V7, V8,
V25, and new non-duplicated breakout candidates through one causal account
governor. V50 remains frozen and unchanged.

Unlike V56, no old add-on decision ledger is replayed. Every add-on acceptance
uses the actual combined closed-equity path available at that decision time.
