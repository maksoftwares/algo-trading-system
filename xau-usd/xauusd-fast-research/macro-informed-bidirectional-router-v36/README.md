# Macro-Informed Bidirectional Router V36

Research-only controlled successor to `bidirectional-action-router-v1`.

The candidate actions, labels, model, walk-forward schedule, 1,000 policies,
economic gates, Core ledger, and risk weights are unchanged. The sole model
change is the addition of causal H1/H4 DXY and Treasury total-return pressure
features available at each candidate timestamp, including their alignment with
each candidate action direction. `PRE_OUTCOME_AMENDMENT.md` records the locked
input-availability amendment made before any V36 economic run.

Historical blocks are already design-contaminated. A survivor is eligible only
for prospective shadow collection and shared-account validation. This package
cannot send broker orders or authorize model serving, EA consumption, demo, or
live trading.
