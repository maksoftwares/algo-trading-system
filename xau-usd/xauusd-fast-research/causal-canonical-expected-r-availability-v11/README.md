# Canonical Expected-R Availability V11

V11 is the evidence-availability policy for the independently verified V10
expected-R model. V10 improved the four folds with at least 1,162 fit rows but
reduced expected R in two earlier folds with only 548 and 817 fit rows.

V11 therefore requires 1,000 eligible fit rows before ML may veto a candidate.
When evidence is below that threshold, the model abstains and every
deterministic candidate is retained. The final V10 research model has 2,851 fit
rows, so it is available for offline scoring.

This remains exposed-history research. V11 does not authorize ML shadowing,
MT5 attachment, demo/live filtering, sizing, serving, or broker action.
