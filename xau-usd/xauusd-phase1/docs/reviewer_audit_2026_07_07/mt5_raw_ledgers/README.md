# MT5 Raw Ledger Audit Bundle

Short-path copy of exact-MT5 `*_trades.csv` and `*_summary.json` files for the 2026-07-07 short-specialist / bearish-branch review packet.

The original MT5 component folders were not committed wholesale because their signal/order logs are hundreds of MB and contain very long Windows paths. This bundle preserves the raw trade ledgers and summary JSON files needed to audit the reported metrics.

See `MANIFEST.csv` for original source filenames, byte counts, and SHA256 hashes.
