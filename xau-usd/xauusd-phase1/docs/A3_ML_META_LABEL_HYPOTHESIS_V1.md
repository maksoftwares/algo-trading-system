# A3 ML Meta-Label Hypothesis V1

Status: PRELOCK_CONTRACT

Scope: A3 account 1033669, XAUUSD only, breakout_retest only.

This contract defines the research question and the shadow-only boundary for the A3 Python ML signal-quality program.

## Research Question

Given a raw breakout-retest signal generated by the existing deterministic logic, a small, calibrated, reproducible Python model can identify a higher-quality subset that outperforms both the raw strategy and fairly tuned deterministic filters without destroying trade frequency.

## System Boundary

The deterministic engine owns:

- signal family;
- direction;
- market level;
- break/retest mechanics;
- entry construction;
- stop construction;
- 1.50R target;
- lot, risk, account, and position-management contract.

Python may output only:

- signal_id;
- setup_group_id;
- model_id and model hash;
- feature schema hash;
- p_win_raw and p_win_calibrated;
- quality score;
- selected threshold;
- TAKE, SKIP, or ABSTAIN;
- score decile;
- drift status;
- explanation fields.

Python must never output or control:

- BUY or SELL;
- entry price;
- stop loss;
- take profit;
- lot size;
- risk percentage;
- magic number;
- broker order;
- position close or modification;
- account reactivation.

## Falsification Criteria

The ML layer is retired when it fails to:

- beat the selected deterministic benchmark under the paired raw-signal comparison;
- preserve useful frequency;
- pass P95-stress absolute and incremental gates;
- produce calibrated probabilities;
- show useful score ranking;
- pass leakage, grouping, feature-budget, and safety audits.
