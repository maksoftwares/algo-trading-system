# Historical Trial Multiplicity

The packet includes all 33 JSON reports found in the repository owner's local
`forex-research/outputs/reports/mt5_backtests/mean_reversion_scout` evidence
directory on 2026-07-23. They contain 114 MT5 result rows across symbols,
timeframes, directions, entry modes, risk/reward values, and selected masks.

`PRIOR_REPORT_INVENTORY.csv` hashes every copied JSON report.
`PRIOR_TRIAL_RESULT_INVENTORY.csv` flattens every result row.
`TRIAL_REGISTRY.csv` identifies the seven directly relevant frozen/raw EURUSD
M30 RSI/Bollinger attribution runs.

This is the complete inventory of the preserved local JSON reports available
for this audit. It is not proof that every informal, failed, deleted, or
unrecorded trial in the research process was preserved. Therefore no DSR or PBO
gate is claimed as passed, and this packet remains development evidence.
